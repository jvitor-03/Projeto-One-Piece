# 🏴‍☠️ Enciclopédia Web - One Piece

Projeto acadêmico de aplicação web estática e responsiva composta por 10 páginas interligadas, desenvolvido para a disciplina de **Desenvolvimento Front-End para Web** do curso de Ciência da Computação da **Universidade Positivo**.

---

## 🚀 Sobre o Projeto

O objetivo do projeto é construir uma enciclopédia temática interativa inspirada no universo de *One Piece*, aplicando os fundamentos essenciais do desenvolvimento web (HTML5 semântico, CSS3 e JavaScript ES6) e o framework Bootstrap 5, garantindo suporte **100% offline** e acessibilidade.

---

## 📌 Funcionalidades e Destaques Técnicos

- **10 Páginas Navegáveis:** Estrutura completa cobrindo Home, Notícias, Curiosidades, Tripulação, Ilhas, Frutas, Piratas, Marinheiros, Shichibukais e Yonkous.
- **Páginas Puras (Vanilla Web):** Páginas como *Tripulação*, *Piratas* e *Shichibukais* desenvolvidas inteiramente sem frameworks externos, utilizando CSS Flexbox e CSS Grid Layout puros.
- **Formulário Interativo com LocalStorage:** Cadastro dinâmico de *Akuma no Mi* com validação nativa de campos, manipulação do DOM e persistência de dados em formato JSON no armazenamento do navegador (`localStorage`).
- **Mídias Locais (Offline):** Reprodução nativa de áudio (`<audio controls>`) e vídeo (`<video controls>`) com arquivos locais, sem dependência de serviços de terceiros ou `iframe`.
- **Design Responsivo & UX/UI:** Layout adaptável a smartphones, tablets e desktops através do sistema de grid de 12 colunas do Bootstrap e Media Queries dedicadas.
- **Acessibilidade & Semântica:** Implementação de atributos W3C/ARIA (`aria-current="page"`, `scope="col"`) e tags semânticas da HTML5.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica e Acessibilidade)
- **CSS3** (Flexbox, CSS Grid Layout, Pseudo-classes e Media Queries)
- **JavaScript (ES6)** (Manipulação de DOM, Arrays de Objetos, Cláusula de Guarda e LocalStorage)
- **Bootstrap 5.3** (Grid responsivo e componentes utilitários)

---

## 📂 Mapeamento das Páginas

1. `index.html` — Hub principal com banner hero e player de vídeo nativo.
2. `noticias.html` — Mural do "Jornal Econômico Mundial" em cards responsivos.
3. `curiosidades.html` — Fatos históricos com player de áudio nativo e CSS incorporado.
4. `tripulacao.html` — Apresentação dos Chapéus de Palha (Página Pura com Flexbox).
5. `ilhas.html` — Tabela de dados de territórios da Grand Line.
6. `frutas.html` — Central de cadastro de Akuma no Mi com JS e `localStorage`.
7. `piratas.html` — Galeria de capitães lendários (Página Pura com CSS Grid).
8. `marinheiros.html` — Hierarquia e patentes da Marinha.
9. `shichibukais.html` — Registro dos Lordes Corsários (Página Pura).
10. `yonkous.html` — Imperadores do Novo Mundo.
